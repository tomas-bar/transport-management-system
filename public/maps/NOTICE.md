# Map data

Natural Earth 1:50m Admin 0 countries and populated places, public domain.
Coordinates rounded to 4 decimals and unused metadata omitted.

Sources:
- https://www.naturalearthdata.com/about/terms-of-use/
- https://github.com/nvkelso/natural-earth-vector/tree/master/geojson

Borders are generalized for contextual display and do not define legal boundaries.
Routing is provided separately by OSRM using OpenStreetMap data.
